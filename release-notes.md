# StreamHub Windows v2.5.0

## YouTube Shorts
- A **Shorts** tab (Home · Shorts · Subscriptions · History · Watch later): one vertical Short at a time, looping.
- Mouse wheel, ↑ ↓ or the buttons for the next and previous Short; **M** sound on/off (remembered), **Space** pause, copy link, and open in the player.
- No ads, and SponsorBlock as usual. In the highest quality YouTube has from the start.
- The next Shorts load in the background while you watch, and the first ones are got ready as soon as you open YouTube, so they start quickly.

## Install
StreamHub updates itself: click **Restart to update** in the banner, or close StreamHub. If it doesn't install, run the installer below by hand; the update log is in `%TEMP%\StreamHub-update\update.log`.
- **StreamHub_2.5.0_x64-setup.exe**: installer (installs over 2.x, settings are kept)
- **StreamHub-2.5.0-Windows-x64-portable.zip**: unzip and run StreamHub.exe (keep the streamlink-plugins folder next to it)

Needs [Streamlink](https://streamlink.github.io/install.html) 8.3 or newer for Twitch and Kick (and a video player such as VLC unless you use Play in StreamHub). The installer isn't code-signed yet: if Windows SmartScreen warns when you install it by hand, choose More info → Run anyway.
